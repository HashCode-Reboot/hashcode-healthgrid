# Roadmap V0.1

Foundation: validate care-coordination problem, actors and constraints.

Architecture: define case, referral, team, consent and audit models.

MVP: deliver referral/task/timeline workflow with access control and auditability.

Validation: run a simulated or approved pilot workflow, measure coordination time and completion rate.

Release: complete security/privacy review, tests, documentation, limitations and impact evidence before V0.1.
