# Contribuer à HealthGrid

Point d'entrée : https://github.com/HashCode-Reboot/hashcode-contributors.

Toute contribution doit distinguer clairement produit, recherche et fonction clinique. Ne pas utiliser de données médicales personnelles réelles hors cadre autorisé.

Une PR doit expliquer problème, solution, tests, limites, sécurité et impact attendu. Les fonctions cliniques sensibles nécessitent une revue humaine compétente.
